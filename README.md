# Catch the Killer: Morgan Morse

Welcome to the **Catch the Killer: Morgan Morse** interactive investigation game! This repository contains the source code for the digital companion app used in the game.

This app works as a static website. You don't need any complex servers or databases to run it. You can either run it directly on your computer or host it for free using **GitHub Pages**.

## 🚀 How to Play Locally (On Your Computer)

If you just downloaded this project and want to play immediately:
1. Unzip the downloaded folder.
2. Open the folder and double-click the `index.html` file.
3. It will open in your default web browser (Chrome, Safari, Edge, etc.) and you can start playing!

> [!TIP]
> The game is built to work fully offline once loaded. You don't need an active internet connection to use the QR scanner, listen to audio files, or read hints!

## 🌐 How to Host on GitHub Pages (For Free)

If you want to share this game with your friends via a link (e.g., `https://your-username.github.io/catch-killer-morze`), you can host it for free using GitHub Pages. 

Follow these simple steps:

### Step 1: Fork this Repository
1. Log in to your [GitHub](https://github.com/) account.
2. Go to this repository's page.
3. In the top-right corner, click the **Fork** button to create a copy of this project under your own account.

### Step 2: Enable GitHub Pages
1. Go to your newly forked repository on GitHub.
2. Click on the **⚙️ Settings** tab near the top of the page.
3. On the left sidebar, scroll down and click on **Pages** (under the "Code and automation" section).
4. Under the **Build and deployment** section:
   - Source: Select **Deploy from a branch**.
   - Branch: Select **main** (or master) from the dropdown, and leave the folder as **/(root)**.
   - Click **Save**.

### Step 3: Wait for Deployment
GitHub will now build your site. This usually takes about 1-2 minutes.
You can refresh the **Pages** settings screen to see your live link, which will look something like this:
`https://[your-username].github.io/catch-killer-morze`

Click the link, and you're ready to investigate! 🕵️‍♂️

## 📱 Mobile App (PWA)

This game supports **Progressive Web App (PWA)** technology. 
If you open your live GitHub Pages link on a smartphone:
1. Your browser will prompt you to **"Add to Home Screen"** or **"Install App"**.
2. Accept the prompt, and the game will be installed as a native-like application on your phone.
3. You can now launch it directly from your home screen, and it will work completely offline!
